# GNN vs TabPFN · water anomaly explorer

Interactive companion to the draft article *Graph neural networks versus TabPFN for anomaly detection in water
infrastructure under label scarcity* (version 0.4, 12 October 2026): every table, figure and number of the
article, computed from the per-run results of the study, plus the full text.

Open it at **https://boukoftanebilal.github.io/gnn-vs-tabpfn-explorer/**

The page is a single static HTML file (CSS, JavaScript, data and figures inlined; charts with Apache ECharts, text with marked and KaTeX) and
is not indexed by search engines. Datasets: HAI 23.05 (CC BY-SA 4.0), SKAB, Smart-Farm-IDS (CC BY 4.0),
WDSEventDB (CC BY 4.0), GECCO 2018 Industrial Challenge (CC BY 4.0).
